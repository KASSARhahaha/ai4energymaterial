## 说明

- 纯静态单页，没有构建步骤，也不依赖任何外部 CDN 或字体服务。
- 首屏等距场景为概念示意，不代表已建设备。
- 工作台截图来自演示模式，数据为合成演示数据。
- 研究数据来自团队成员已发表论文；「计算 vs 实验」图表的数值读自 Adv. Funct. Mater. 2023 原图（约 ±0.1 V），以原文为准。
